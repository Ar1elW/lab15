# Lab15 Shop - система управления заказами интернет-магазина

Консольное приложение на языке Java для оформления и обработки заказов интернет-магазина. Разработано в рамках лабораторной работы №15 с использованием системы управления версиями Git и хостинга GitHub.

## Назначение

Приложение хранит каталог товаров двух видов (физические и цифровые), позволяет оформлять заказы, рассчитывать их стоимость с учётом доставки, менять статусы заказов и отменять их. Данные сохраняются в файлы и восстанавливаются при следующем запуске.

## Возможности

- добавление, просмотр, поиск по названию и удаление товаров;
- два вида товаров: физические (доставка зависит от веса) и цифровые (доставка бесплатная);
- создание заказов и добавление в них товаров;
- расчёт итоговой стоимости заказа с учётом доставки и скидки 5 процентов при покупке от 10 единиц одного товара;
- изменение статуса заказа по цепочке: Новый, Оплачен, Отправлен, Выполнен;
- отмена заказа, при этом отмена выполненного заказа запрещена;
- поиск заказов по статусу и отчёт по заказам с выручкой;
- сохранение данных в файлы папки data и загрузка при запуске;
- проверка корректности вводимых данных и понятные сообщения об ошибках.

## Требования

- JDK 11 или новее;
- Git (для работы с репозиторием).

## Запуск

Через среду разработки: открыть папку проекта в IntelliJ IDEA и запустить класс `com.shop.Main`.

Через командную строку из корня проекта:

Windows:

    javac -encoding UTF-8 -d out src\com\shop\*.java src\com\shop\*\*.java
    java -cp out com.shop.Main

Linux и macOS:

    javac -encoding UTF-8 -d out $(find src -name "*.java")
    java -cp out com.shop.Main

Самопроверка основных сценариев:

    java -cp out com.shop.test.SelfTest

## Архитектура

Проект разделён на пакеты по ответственности:

- `com.shop.model` - классы предметной области: абстрактный `Product`, наследники `PhysicalProduct` и `DigitalProduct`, `Order`, `OrderItem`, перечисление `OrderStatus`, интерфейсы `Identifiable` и `Savable`;
- `com.shop.exception` - собственные исключения `OrderException` и `DataFormatException`;
- `com.shop.repository` - обобщённый класс `Repository<T>` для хранения объектов в коллекции;
- `com.shop.service` - бизнес-логика магазина (`ShopService`);
- `com.shop.storage` - интерфейс `DataStorage`, его файловая реализация `FileDataStorage` и разбор строк файла `DataParser`;
- `com.shop.ui` - консольное меню `ConsoleMenu`;
- `com.shop.util` - вспомогательные классы форматирования и проверки текста;
- `com.shop.test` - класс `SelfTest` для проверки основных операций.
